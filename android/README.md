# 墨间 · 安卓版

适用于 Android 8.0 及以上。使用系统 PDF 引擎，纯本地运行，无网络权限、无需账号。APK 同时适用于常见 ARM 手机、平板和 x86 安卓模拟器。

## 安装与导入

把 `Mojian-Android-1.1.1.apk` 传到手机，用系统文件管理器打开安装。如果系统询问安装来源权限，允许本次使用的文件管理器安装即可。

打开墨间 →「导入」→ 选择一本漫画的文件夹 →「使用此文件夹」并授权。文件夹名成为漫画名，里面的 PDF（包含子文件夹）成为章节。自动识别中文章号、Chapter/数字名称、小数章号和番外；支持在详情页调整顺序、修改漫画名。

导入后会复制 PDF 到应用专属 `comics` 子目录，阅读不依赖原文件夹。原文件不会被移动或删除。已加密或损坏的 PDF 会中止该本漫画导入；更新时保留原有完整副本与进度。

## 直接放文件夹到书库

在手机 Documents 下建立一个目录，例如 `Documents/墨间`：

```text
Documents/墨间/
  第一部漫画/
    第1话.pdf
    第2话.pdf
  第二部漫画/
    chapter 01.pdf
    chapter 02.pdf
```

在「偏好 → 书库根目录」选择 `Documents/墨间`。以后把漫画文件夹复制进去，点击书架右上角刷新即可扫描。扫描会添加新漫画、更新已有章节；保留自定义漫画名与阅读进度。个别漫画无法导入时，会列出原因并继续处理其他漫画。

安卓对应用目录有访问限制，因此批量投放使用你自己选择的总目录。系统可能不允许选择整个内部存储根目录、Download 根目录、Android/data 等位置；可使用 Documents 下自行创建的目录。应用保留系统授予的根目录读取权限，供以后刷新使用。

## 阅读

阅读工具栏支持约 250 毫秒的滑动与淡入淡出过渡，阅读区域随工具栏一起平滑伸缩。快速重复点击会从当前状态反向过渡，退出阅读或切换布局会取消旧动画。在「偏好 → 界面动画」关闭后，上下栏直接切换。

新增「条漫模式」：在阅读界面右上角设置 →「页面布局 → 条漫模式」启用，也可在偏好设置中选择。

条漫按屏幕宽度将整本漫画的 PDF 页面上下连续排列，滑动到底自动衔接下一章，页面之间不添加间距或阴影。支持惯性滚动、双指缩放、双击放大、目录/页码跳转与沉浸阅读。轻点页面显示或隐藏工具栏；条漫始终从上往下阅读，不随横屏切成双页。

条漫会保存当前章节、页码和页内滚动位置。退出后继续阅读或旋转屏幕，会恢复相应位置。百分比随滚动推进，到全书底部后标记读完。可以随时切回单页、双页或随屏幕旋转模式。

超长 PDF 使用分块渲染，仅加载屏幕附近的图像，位图缓存上限为 24 MiB。原 PDF 自带的留白会保留。

- 默认随屏幕旋转：竖屏单页、横屏真实双页；可以手动选择单页或双页。
- 左右滑动、点击两侧或底部箭头翻页；支持跨章节连续阅读。
- 轻点中央隐藏/显示工具栏；双指缩放、双击放大；适合宽度时可上下拖动。
- 点击底部页码跳转；拖动进度条定位；顶部目录切换章节。
- 支持从右向左阅读，双页顺序和翻页方向一起改变。
- 翻页动画可选轻滑、淡入、舒展和直接切换，另有界面动画开关。
- 双页之间仅留背景色间隙，无书脊、阴影或纸张边缘。奇数末页单独居中。

进度在页面成功显示后保存；双页保存当前显示的最后一页。关闭后可从书架的「继续阅读」恢复。

## 数据与版本

这是独立的安卓应用，Windows 版的 SQLite 书库和进度不会自动同步。可以复制同一批漫画 PDF 到手机后导入。卸载或清除安卓应用数据会删除应用内的导入副本和进度，请保留原始漫画文件夹。覆盖安装同一签名的新版本会保留应用数据。

## 构建

源代码使用 Java 8 语法和 Android 平台 API，不依赖外部阅读库。常规 Gradle 工程位于本目录，可在 Android Studio 导入；AGP 为 8.7.3，使用 JDK 17、Gradle 8.9、compileSdk 35，最低 API 26。

也提供 Windows 离线打包脚本，从项目根目录运行：

```powershell
.\android\build.ps1
# 编译额外的测试 APK
.\android\build.ps1 -Test
```

脚本使用 `.tools/android` 内的 JDK、Android 35 平台和 Build Tools 35，通过 aapt2 → javac → D8 → zipalign → apksigner 构建。也可以设置 `JAVA_HOME` 与 `ANDROID_HOME`，使用自己的 SDK。首次构建会在 `.tools/android` 生成本地签名密钥和随机口令，后续构建复用同一密钥以支持覆盖升级。私钥和口令不要删除或分发；源代码包不包含它们。

输出：`release/android/Mojian-Android-1.1.1.apk` 和 SHA-256 校验文件。

## 验证

`tests` 中是独立测试 APK：使用独立 DocumentsProvider 提供原创测试 PDF，在实际 Android 系统中验证递归导入、排序、重命名与进度持久化、真实双页像素、右向左、奇数末页、跨章导航、触摸滑动、旋转、失败回滚、复制中取消和根目录批量扫描。

只能在无个人数据的测试设备运行测试。测试 APK 不包含在正式 APK 中。通过与主 APK 相同的签名安装测试 APK 后：

```text
adb shell am instrument -w com.mangashelf.mojian.tests/com.mangashelf.mojian.ReaderInstrumentation
```

测试开始需要空书库；它会写入虚构漫画和截图。正式 APK 不包含测试数据或用于测试的 Provider。

条漫专项检查位于 `WebtoonInstrumentation`，在普通阅读检查完成后运行：

```text
adb shell am instrument -w com.mangashelf.mojian.tests/com.mangashelf.mojian.WebtoonInstrumentation
```

覆盖连续排页、真实纵向手势、跨章、页内进度、旋转、跳转、切回双页、超长页分块像素、缓存限制、缩放和读完标记。`tests/run.ps1` 可在全新测试模拟器上一并运行两套检查，并清理测试应用。

工具栏动画的逐帧检查位于 `ChromeInstrumentation`：验证淡入淡出与高度的中间帧、快速反向点击、动画开关、旋转、退出时取消，以及条漫实际点击后的位置保持。
