# 墨间 · 漫画阅读器

Windows 与 Android 本地 PDF 漫画阅读软件。每个文件夹为一本漫画，每个 PDF 为一个章节，支持离线使用。

<img src="mangashelf/assets/mangashelf.png" alt="墨间图标" width="96" />

| 平台 | 当前版本 | 阅读方式 |
| --- | --- | --- |
| Windows x64 | 1.4.1 | 单页、双页并排、从右向左阅读 |
| Android 8.0+ | 1.1.1 | 单页、横屏双页、纵向连续条漫、手势缩放 |

安装包在 [Releases](https://github.com/sekai147/Mojian-MangaShelf/releases/latest) 页面下载。源码仓库包含完整工程、测试、图标和构建脚本；生成的安装包单独附在 Release 中。

两端都支持漫画文件夹导入、中文/数字章节自动排序、自定义漫画名与阅读进度。安卓条漫支持跨章连续滚动、页内位置恢复和上下工具栏的滑动淡入淡出。Windows 与 Android 的书库和阅读进度分别保存。

安卓使用方法、书库根目录设置与 APK 构建见 [安卓说明](android/README.md)。下文主要介绍 Windows 版本。

应用图标采用墨绿底、米白漫画书与暖棕书签，已应用于侧栏、程序窗口、任务栏和 Windows EXE。图标的可编辑 SVG、512px PNG 与多尺寸 ICO 位于 `mangashelf/assets`，可运行 `scripts/build_icon.py` 重新生成；打包时会自动生成和嵌入。

## 直接运行

从 Releases 下载 `MangaShelf-Setup-1.4.1-x64.exe`（本地构建输出到 `release/installer`）。双击后按中文向导操作，可选择安装目录和桌面快捷方式；默认安装到当前用户的 `LocalAppData/Programs/MangaShelf`，无需管理员权限和 Python。卸载会保留安装目录的 `comics` 和 `data`。

从便携版迁移时，先关闭软件，将原来的 `comics`、`data` 两个文件夹复制到安装目录，再启动即可恢复漫画库和进度；目标已有书库时应先备份。

便携包解压后双击 `MangaShelf.exe`；在源码工作区中，该程序位于 `release/墨间漫画阅读器/`。便携版无需安装 Python；请保留同目录下的 `_internal` 文件夹。首次运行会在程序旁创建 `data` 目录，用于书架、封面和阅读进度。整个软件文件夹应放在可写入的位置。

1. 点击“导入漫画文件夹”，或拖入文件夹。也可按 `Ctrl+O`。
2. 选取含有 PDF 章节的文件夹。会递归扫描子文件夹，将它们归入同一本漫画。
3. 漫画名称默认使用所选文件夹名，可在导入时修改，或稍后在漫画详情中重命名。
4. 确认后，整个文件夹会复制到程序旁的 `comics/` 漫画库；保留子目录和附带文件。复制完成后即可移动或删除源文件夹。
5. 在章节目录双击章节阅读。目录支持拖动调整顺序和恢复自动排序。
6. 再次导入同一源文件夹会更新对应副本并保留书名和阅读进度；不同来源的同名文件夹会自动加后缀分别保存。复制在后台进行，可以取消；失败时保留原有漫画库。
7. “更新章节”会扫描书架当前使用的漫画文件夹。可直接把新 PDF 放进漫画库后更新，或重新导入含有新章节的源文件夹。

## 直接放入软件子目录

也可以直接把文件夹复制或移动到程序旁的 `comics` 目录中，一本漫画一个文件夹，例如：

```text
墨间漫画阅读器/
  MangaShelf.exe
  comics/
    漫画A/
      第1话.pdf
      第2话.pdf
    漫画B/
      001.pdf
      002.pdf
  data/
  _internal/
```

启动软件时会自动识别新放入的漫画文件夹。软件已打开时，点击左下角书库卡片中的刷新图标（扫描漫画库），即可识别新增漫画和更新章节；“打开漫画库”可直接打开这个目录。直接放入的文件夹会原地识别，不会重复复制。书名默认为文件夹名，之后可在软件里重命名。

移出书架会保留漫画库中的 PDF，同时清除书架记录和进度；下次启动不会自动加回。手动点击“扫描漫画库”可以重新加入。

## 排序规则

支持 `001.pdf`、`第十二话.pdf`、`第2.5话.pdf`、`Chapter 10.pdf`、`ch.002.pdf`、`[015] 漫画.pdf`、`漫画 102.pdf` 等文件名。优先使用识别的章节号，未识别的文件按文件名自然排序，番外/特典/Extra 放在最后。鼠标悬停章节可查看识别的章节号及原路径。

识别依据是文件名，不会对 PDF 页面进行 OCR。若章节文件名没有可识别的编号，可以在导入前重命名文件，或在章节目录拖动调整顺序。多个卷分别从第 1 话重新编号时，建议使用连续编号或手动调整。普通单页损坏会在打开该页时提示。

## 阅读操作

| 操作 | 快捷键 |
| --- | --- |
| 翻页 | 左右方向键、PageUp / PageDown |
| 下一页 | 空格 |
| 本章首页 / 尾页 | Home / End |
| 全屏 | F11 |
| 退出全屏 / 返回书架 | Esc |
| 导入文件夹 | Ctrl+O |

阅读器默认双页并排，完整展示相邻的两张 PDF 页面，每次翻页前进两页。中间只保留窄缝；没有额外的书脊、页间阴影或纸张边框。章节末尾不足两页时单独居中显示，不会重复上一页凑成一对。

顶部可切换章节、双页/单页及缩放，图标按钮用于展开目录、阅读设置和全屏。目录默认收起；底部提供页码输入、进度拖动和阅读方向提示。页码输入任意一页时，双页模式会跳到包含该页的一组。

支持画面适配、宽度适配、75%—200% 缩放和跨章翻页。在阅读设置中启用“从右向左阅读”，会把较早页放在右侧，同时交换左右翻页方向。阅读进度在页面成功加载后保存到当前显示的最后一页；显示本章末页后，该章标为已读。布局和阅读方向会自动保存。

## 界面与切换动画

书架分类、搜索和排序结果采用轻上浮渐入，漫画详情采用缩放弹出，书架与阅读器之间采用双向滑动过渡，阅读器的章节目录支持平滑展开和收起。

阅读设置中可以选择“滑动”“淡入”“翻书”或“关闭”，翻页和跨章切换都会使用所选效果；从右向左阅读时同步反转动画方向。缩放页面时使用短暂淡入过渡。

点击左下角“设置”或阅读器顶部的设置图标打开偏好面板。“阅读体验”页提供双页/单页布局、阅读方向、动画开关和四种翻页效果；“书库与帮助”页可查看、打开漫画库，阅读快速指南与快捷键。偏好会自动保存并与阅读器同步。动画时长约 190—260 毫秒，连续操作会取消旧动画并显示最新结果，动画不会拦截鼠标操作。

## 文件与备份

通过软件导入会复制整个漫画文件夹到程序旁的 `comics` 目录，源文件不会被修改或删除。导入完成后，阅读使用副本，不再依赖源文件夹的位置。直接放入 `comics` 的文件夹则原地使用。

备份程序旁的 `data` 和 `comics` 两个文件夹，可一并备份书架、进度与漫画。移动整个软件文件夹后，会自动更新漫画库和封面的路径。旧版已导入的漫画需要再导入一次（或点击“更新章节”），即可复制到新漫画库并保留原书名与进度。加密 PDF 须自行移除密码后导入。软件不上传漫画文件，无需账号和网络。

## 从源码运行

另有独立的安卓原生版本（Android 8.0+），安装 APK 位于 `release/android`，支持文件夹导入、书库根目录扫描、手机触屏阅读与横屏双页。详见 [安卓使用与构建说明](android/README.md)。Windows 与安卓的书库及阅读进度分别保存。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

可以用 `--data-dir 路径` 指定独立数据目录，此时漫画保存在该数据目录的 `comics` 子目录中。

## 检查与打包

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\build.ps1
```

构建安装版需要 Inno Setup 的 `ISCC.exe`（可在 `.tools/inno` 便携放置，或用 `-CompilerPath` 指定）：

```powershell
.\build_installer.ps1 -ReleaseName '墨间漫画阅读器'
```

安装脚本和向导品牌素材位于 `installer`。输出包含安装 EXE 和 SHA-256 校验文件，安装内容按程序文件白名单收集，不打包个人的漫画与数据。可用 `scripts/test_installer.ps1` 在工作区测试安装、启动、覆盖安装和卸载；若已存在正式安装，该测试会停止以保护其注册信息。

测试会生成原创几何图案 PDF，验证真实导入、排序、复制、目录发现、旧书架迁移、重名处理、复制取消和失败恢复、书名与进度保存、整个软件目录搬迁、渲染、跨章翻页和异常 PDF 处理。界面截图位于 `test-output`。

打包使用 PyInstaller，依赖 PySide6 Essentials（LGPLv3）与 PyMuPDF（AGPLv3/商业许可）。本项目源码以 AGPLv3 发布，详见 `LICENSE.txt`。如计划闭源分发，需要自行安排合适的依赖许可。
